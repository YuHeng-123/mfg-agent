# HE800 板式换热器 使用与维护手册

## 1.1 适用范围

本手册适用于 HE800 型可拆卸板式换热器，用于工艺物料与循环水的换热。设计压力 1.0 MPa，设计温度 120 ℃，板片材质 316L，垫片材质三元乙丙橡胶。同系列 HE600 与 HE1000 的板片波纹角不同，板片不得混装。

## 1.2 介质限制

垫片为三元乙丙橡胶，不得用于芳烃、酯类与酮类介质。氯离子浓度超过 200 mg/L 时，316L 板片存在应力腐蚀风险，须评估后使用。介质中颗粒粒径不得超过 0.8 mm，否则须在入口加装过滤器。

## 2.1 安全注意

> 警告：拆解换热器前必须关闭冷热两侧进出口阀门，泄压并排空，确认两侧压力表均回零。

> 警告：板片边缘锋利，拆装须戴防割手套。板片组夹紧状态下不得敲击或撬动板片。

> 警告：重新夹紧时须按对角顺序分次均匀施力，一次夹紧到位会导致板片变形与垫片错位。

## 3.2 结构与流程

换热器为单流程逆流布置，冷热介质在相邻板片间交替流动。板片密封由垫片在夹紧力作用下形成，夹紧力由两侧夹紧螺栓提供。铭牌上的夹紧尺寸是拆装复位的唯一依据，检修后必须复测。

## 4.1 故障代码总表

| 代码 | 名称 | 常见原因 |
| H01 | 换热效率下降 | 板片结垢、垫片老化内漏 |
| H02 | 压降升高 | 流道堵塞、板片结垢 |
| H03 | 外漏 | 垫片老化、夹紧尺寸超差 |
| H04 | 内漏 | 板片穿孔、垫片串漏 |
| H05 | 板片腐蚀穿孔 | 氯离子应力腐蚀、介质超标 |
| H06 | 夹紧尺寸变化 | 螺栓松弛、垫片压缩永久变形 |
| H07 | 异响与振动 | 流量过大、气体未排净 |
| H08 | 温度控制偏差 | 传感器漂移、旁路阀内漏 |

## 4.2 故障代码 H01 换热效率下降

现象：出口温度达不到工艺要求，冷热端温差减小，压降可能同时升高。

可能原因：板片结垢使传热系数下降；垫片老化导致内漏使介质短路；板片数量少于设计值。

处置步骤：

1. 对比设计工况记录进出口温度，计算当前传热温差。
2. 若压降同时升高，判定为结垢，安排拆解清洗。
3. 若压降正常而效率下降，怀疑内漏，须拆解检查垫片与板片。

## 4.3 故障代码 H02 压降升高

现象：单侧或两侧压降超过 0.08 MPa，流量下降。

可能原因：流道内结垢或沉积物；入口过滤器堵塞；板片装反导致流道错位。

处置步骤：

1. 检查入口过滤器压差，超过 0.05 MPa 须清洗。
2. 拆解检查板片表面结垢情况，采用软刷与中性清洗剂，禁止用钢丝刷。
3. 复装时确认板片方向，全部板片波纹应朝向一致。

## 4.4 故障代码 H03 外漏

现象：板片组外缘或夹紧螺栓处可见介质渗漏。

可能原因：垫片老化失去弹性；夹紧尺寸小于铭牌值；板片变形；螺栓松弛。

处置步骤：

1. 测量夹紧尺寸，小于铭牌值 2 mm 以内可补紧至铭牌值，补紧后仍漏须更换垫片。
2. 补紧须按对角顺序分三次施力，每次不超过设计力矩的三分之一。
3. 更换垫片时须整体更换，不得混用不同批次垫片。

## 4.5 故障代码 H05 板片腐蚀穿孔

现象：内漏且两侧介质交叉污染，拆解后可见板片穿孔或点蚀。

可能原因：氯离子超标的应力腐蚀；介质温度超过垫片与板片允许值；停机期间未排空导致缝隙腐蚀。

处置步骤：

1. 取样分析介质氯离子浓度与 pH 值。
2. 穿孔板片必须更换，禁止补焊。
3. 长期停机须排空并冲洗，保持干燥。

## 5.1 维护周期

| 项目 | 周期 | 备注 |
| 压降记录 | 每班 | 超过 0.08 MPa 报警 |
| 夹紧尺寸复测 | 每年 | 与铭牌值比对 |
| 拆解清洗 | 压降超标或每年 | 结垢严重时缩短 |
| 垫片更换 | 3 年或泄漏时 | 整体更换 |
| 板片测厚 | 5 年 | 减薄超过 0.1 mm 更换 |
