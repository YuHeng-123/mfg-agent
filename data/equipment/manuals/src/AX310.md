# AX310 螺杆空压机 使用与维护手册

## 1.1 适用范围

本手册适用于 AX310 型喷油螺杆空气压缩机。AX310 与 AX300 外观相近、故障代码表基本一致，但排气量、滤芯规格、联轴器力矩与报警阈值均不相同，检修时不得混用 AX300 的参数。这是同系列机组最常见的事故来源。

## 2.1 安全注意

> 警告：检修前必须断开主电源并挂牌上锁（LOTO），确认变频器直流母线放电完毕（等待 5 分钟）后方可开柜。

> 警告：机组运行期间排气温度可达 105 ℃ 以上，排气管道与冷却器表面禁止徒手触摸，禁止带压拆检。

## 3.1 主要技术参数

| 项目 | 参数 | 备注 |
| 排气量 | 5.4 m3/min | 额定工况 |
| 额定排气压力 | 0.8 MPa | 可调范围 0.6 至 0.85 |
| 排气温度报警值 | 108 ℃ | 超过即触发 E05 |
| 排气温度停机值 | 118 ℃ | 超过即联锁停机 |
| 润滑油容量 | 32 L | 推荐换油周期 4000 h |
| 冷却水进水温度 | ≤ 34 ℃ | 出水温升不超过 8 ℃ |
| 滤芯更换压差 | 0.12 MPa | 压差表读数 |
| 振动速度报警值 | 4.0 mm/s | 主机轴承座测点 |
| 联轴器复紧力矩 | 180 N·m | 不得按 AX300 的 210 N·m 执行 |

## 4.1 故障代码总表

| 代码 | 名称 | 常见原因 |
| E05 | 排气温度过高 | 冷却水中断、冷却器结垢、滤芯堵塞 |
| E06 | 油温过高 | 油冷却器脏堵、油位过低 |
| E08 | 主机振动超标 | 联轴器对中不良、轴承磨损 |
| E09 | 电流过载 | 电压偏低、主机抱死 |

## 4.2 故障代码 E05 排气温度过高

现象：排气温度显示超过 108 ℃ 报警，超过 118 ℃ 机组联锁停机。

可能原因：冷却水中断或流量不足；冷却器结垢；空气滤芯堵塞；润滑油量不足。

处置步骤：

1. 将机组降载至 60% 以下，确认冷却水阀开度与流量开关状态。
2. 读取冷却器进出水温差，超过 8 ℃ 安排化学清洗。
3. 读取滤芯压差表，压差超过 0.12 MPa 应更换 AX310-F 滤芯。
4. 检查油位，低于视窗中线须补油至规定刻度。

## 4.3 故障代码 E08 主机振动超标

现象：主机轴承座测点振动速度超过 4.0 mm/s，面板报警。

可能原因：联轴器对中不良；弹性体老化；地脚螺栓松动。

处置步骤：

1. 停机按 180 N·m 复紧地脚螺栓。
2. 复测联轴器径向偏差，不超过 0.05 mm。
3. 振动仍超标须拆检主机轴承。

## 5.1 维护周期

| 项目 | 周期 | 备注 |
| 空气滤芯 | 压差 0.12 MPa 或 1800 h | 以先到为准 |
| 润滑油 | 4000 h | 油样超标提前更换 |
| 联轴器检查 | 8000 h | 含对中复测 |
