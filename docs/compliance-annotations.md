# 体检域 20 条标注（判定记录）

> 标注已经定稿，本文是判定依据的存档，不是待办。谁再问"这 20 条为什么这么标"，答案在这里。

标注是评测的地基：标注错了，指标就是在量一个不存在的东西。所以这 20 条单独列出来过一遍。
重点是 **C-10 ~ C-13**——它们的 gold 是「不该报任何差距」，这是四类里最容易标错的一类。

---

## 先说判据

`domains/compliance/requirements.py` 里只有 7 条要求，覆盖 5 个条款：

| gap_id | 条款 | 要求厂内文件出现 | 比对对象 |
|---|---|---|---|
| G-01 | 7.1.6-a 组织知识 | 知识 / 来源 / 更新 | 质量手册 §4.2.3 |
| G-02 | 7.1.6-b 组织知识 | 经验 / 流失 | 培训教材 §3 |
| G-03 | 6.3 变更的策划 | 变更 / 影响评估 | 质量手册 §7.5 |
| G-04 | 7.5.3 成文信息的控制 | 版本 / 更改控制 | 质量手册 §7.5 |
| G-05 | 10.2 不合格和纠正措施 | 不合格 / 原因 / 纠正措施 | 检验规程 §6 |
| G-06 | 7.1.6 组织知识 | 存在《组织知识管理程序》 | 全库（缺文件） |
| G-07 | 5.1.1 领导作用和承诺 | 存在质量文化证据 | 全库（缺文件） |

**判据就一句：问题问到的条款是否落在这 7 条要求的范围内。** 不在范围内 → 不报差距。

---

## C-10 ~ C-13：四条「不该报差距」

这四条问的条款都在标准节选里（所以能答、要答），但**都不在 7 条要求范围内**，所以差距清单必须为空。

| id | 问题 | 实际问的条款 | 为什么不是差距 |
|---|---|---|---|
| C-10 | 文件的标识和批准由谁负责 | 7.5.2 标识和批准 | 与 G-04（7.5.3 版本与更改控制）是**相邻但不同的子条款**。厂内文件写了版本控制要求，标识与批准不在本轮比对范围 |
| C-11 | 关键控制点要记录哪些参数 | 8.5.1 生产和服务提供的控制 | 7 条要求里没有 8.x 系列条款 |
| C-12 | 客户满意度调查多久做一次 | 9.1.2 顾客满意 | 7 条要求里没有 9.x 系列条款 |
| C-13 | 体系覆盖哪些过程 | 4.3 确定管理体系范围 | 7 条要求里没有第 4 章条款 |

**判定**：这四条标 `no_gap`（能答、答的是条款原文、不报差距），而不是 `refuse`（越界拒答）。
理由：条款原文确实在库里，答得出来；拒答会让系统显得"明明有还装不知道"。

一个备选方案被否掉了：让系统在这种时候多说一句「本轮只比对 7 条要求，该条款不在范围内」。
它更严谨，但代价是每条 no_gap 答案都多一段免责声明，演示时反而模糊重点。
备选记在这里，如果以后要对接真实贯标流程再启用。

## 其余 16 条

**C-01 ~ C-06 · gap_exists（应报差距）**

| id | 问题 | gold gap | gold 段落 |
|---|---|---|---|
| C-01 | 对照新版 7.1.6 组织知识，我们质量手册要改哪几处 | G-01, G-02, G-06 | 标准 §7.1.6 + 质量手册 §4.2.3 + 培训教材 §3 |
| C-02 | 6.3 变更的策划对现有文件有什么影响 | G-03 | 标准 §6.3 + 质量手册 §7.5 |
| C-03 | 7.5.3 成文信息控制的要求和我们现行文件控制差在哪 | G-04 | 标准 §7.5.3 + 质量手册 §7.5 |
| C-04 | 我们的不合格品处置符合 10.2 吗 | G-05 | 标准 §10.2 + 检验规程 §6 |
| C-05 | 换版后质量文化方面需要补什么 | G-07 | 标准 §5.1.1 |
| C-06 | 组织知识这块我们缺哪些文件 | G-01, G-02, G-06 | 标准 §7.1.6 + 质量手册 §4.2.3 + 培训教材 §3 |

C-01 与 C-06 的 gold 相同：一个问"改哪几处"、一个问"缺哪些文件"，指向同一批差距。
**这是故意的重叠**——同一件事的两种问法，系统不该给出两个答案。

**C-07 ~ C-09 · missing_doc（缺整份文件）**

| id | 问题 | gold gap | 说明 |
|---|---|---|---|
| C-07 | 我们有没有组织知识管理的程序文件 | G-06 | 全库无此文件 |
| C-08 | 有没有质量文化相关的证据记录 | G-07 | 全库无此文件 |
| C-09 | 我们规定了知识更新方式吗 | G-01 | 文件在，但 §4.2.3 没写更新方式 |

C-07/C-08 与 C-09 的区别是"缺文件"和"文件在但没写到"，对应 `missing_doc` 与 `missing_section` 两类规则。

## 当前实测（这 20 条上跑出来的）

```
差距召回 100%   差距精确 100%   误报 0 项
无差距题判空正确率 100%（4/4）       ← C-10~C-13 全对
引用精确率 64.1%   引用命中率 76.9%   引用覆盖率 73.1%
拒答正确率 100%（7/7）   误拒率 0%（0/13）
```

判空正确率 100% 有个前提要说清：**4 条样本全对，样本量太小。** 它能说明机制对，不能说明鲁棒。
真要较真，这类题应该做到 15-20 条（把 4.x / 8.x / 9.x 各铺几条），这是下一轮的事，已写进 TODO。
