# 检索错误分析（P1）

**数据**：25 条检索样本，`Recall@1 = 68%`，即 7 条 top1 不是正确答案。
**方法**：`python scripts/analyze_errors.py` 把每条失败样本的 gold 段落、top1 段落、查询词命中情况全部打出来，逐条归因。

---

## 归因汇总

| 类别 | 条数 | 说明 |
|---|---|---|
| **A. 标注错误** | 2 | gold 标错了或标窄了，检索其实没错 |
| **B. 元描述段落得分过高** | 4 | 每本手册开头的「1.1 适用范围」压过了真正的答案 |
| **C. 同词不同义** | 1 | 「拆解」在故障处置里出现，在安全注意里也出现 |

**7 条里 4 条是同一个结构性原因**——这比"东一条西一条"好办得多。

---

## A. 标注错误（2 条，必须先改）

### E-16「换热器板片夹紧尺寸怎么控制」

- 我标的 gold：`4.1 故障代码总表`（内容是 `H01 | 换热效率下降 | 板片结垢…`）
- 实际 top1：`3.2 结构与流程`——"铭牌上的夹紧尺寸是拆装复位的唯一依据，检修后必须复测"
- **top1 才是对的。** 我的 gold 是机器按 section 关键字生成的，这一条我自己写错了。

### E-22「HE800 板片厚度减薄多少要更换」

- 我标的 gold：`5.1 维护周期`（"板片测厚 | 5 年 | 减薄超过 0.1 mm 更换"）
- 实际 top1：`3.1 主要技术参数`（"板片厚度 0.5 mm | 减薄超过 0.1 mm 须更换"）
- **两段都对。** 这是"标注过窄"——只标了一个正确答案，另一个正确答案被算成错。

> 这两条说明：**在优化检索之前，先把标注审一遍。** 否则会拿标注的错去改代码。E-16、E-22 改完之后 Recall@1 会直接变化，而这个变化不是检索变好了，是评分变准了——报告里要分开写。

## B. 元描述段落得分过高（4 条，结构性）

失败样本里 top1 反复出现同一类段落：`1.1 适用范围`。

```
E-10  问「HE800 板式换热器外漏怎么补紧」  top1 = 1.1 适用范围
E-14  问「离心泵对中偏差允许范围是多少」    top1 = 1.1 适用范围
E-19  问「换热器垫片多久需要更换」         top1 = 1.1 适用范围
E-24  问「离心泵拆卸前要确认什么」         top1 = 1.1 适用范围
```

原因很清楚：`1.1 适用范围` 这一段**同时包含型号名、设备全称、系列对比**，几乎覆盖了用户提问里的所有设备类词（"HE800""板式换热器""离心泵"），而它的 section 标题又带着章节号，吃到 1.8 的字段权重。

但它的内容是**元描述**——"本手册适用于……同系列 X 与 Y 不同……"——几乎不含任何可执行答案。

这是真实手册的通病：每本都有"适用范围/总则/说明"。**所以这不是我的数据造得不好，是这类语料的固有噪声。**

### 修法（P2 执行）

给低信息量章节加先验降权，名单很短且可解释：

```
适用范围 / 总则 / 说明 / 概述 / 前言  ->  section 权重 1.8 → 0.8
```

更彻底的做法是学"跨文档重复度"（同样的段落出现在多本手册里 → 降权），但那需要更多手册，现在只有 4 本，先用手写名单。名单本身要写进文档，因为它是一个**明确的领域先验**，不是调参。

## C. 同词不同义（1 条）

### E-25「换热器拆解前的泄压要求」

- 正确答案在 `2.1 安全注意`："拆解换热器前必须关闭冷热两侧进出口阀门，泄压并排空"
- top1 是 `4.2 故障代码 H01`：处置步骤里有一句"拆解检查板片"，命中了"拆解"
- gold 排第 2

本质是"拆解"这个词在两个语境里都出现：一个是安全前提，一个是故障处置。BM25 分不出意图差异。

这条我不打算用规则硬修（比如"问题含'前/要求/必须'就偏向安全章节"）——那种规则一写就过拟合。**留着，作为失败案例写进 README**，它说明词面检索的天花板在哪。

---

## 结论与下一步

1. **先改标注**（E-16、E-22），重跑，看 Recall@1 的真实基线。这一步不改任何检索代码。
2. **再做章节先验降权**（B 类，4 条），这是唯一有明确结构原因的优化，值得做。
3. **C 类不改**，留作失败案例。

预期：改标注后 7 条失败剩 5 条；降权后（如果有效）再收敛 1-3 条。**每一步都要有 before/after，没涨也要记录。**

> 一句话总结这次诊断：**68% 这个数字里，有一部分是我自己批错了卷。** 先把这个说清楚，再谈优化。
